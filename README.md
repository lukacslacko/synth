# synth

- `index.html` — Acid Drift, fractal edition: a generative acid techno synth whose UI is a full-screen HDR fractal (Möbius / rational / flame IFS, Kali, Julia) driven by the music. Sliders mix how much the slowly drifting synth parameters, the riff and the spectrum bend each map's shape and colour.
- `synth.html` — the original Acid Drift page with the oscilloscope UI. The audio engine is identical in both files.
